# The Eleruwa of Eruwaland — Official Royal Portal

A Next.js App Router foundation for the official digital platform of the Royal Palace of the Eleruwa of Eruwaland.

## Project status
This Phase 1 foundation is on the rebuild/phase-1-foundation branch. The original static HTML website remains preserved on main and in the Phase 1 backup branch.

## Technology
- Next.js App Router
- React and TypeScript
- Tailwind CSS
- Static generation for editorial sections
- Vercel-compatible configuration

## Local development
1. Install Node.js LTS and npm.
2. Run npm install.
3. Run npm run dev.
4. Open http://localhost:3000.

Run npm run build before proposing a production deployment.

## Content integrity
Do not publish unverified historical, biographical, lineage, title, date, contact or location claims. Existing source-page content must be reviewed with the Palace before migration.

## Images and permissions
Use Palace-owned or Palace-authorized media. Existing externally hosted images require rights and permission review before reuse.

## Environment variables
Copy .env.example to .env.local when a Palace-approved integration is introduced. Never commit secrets.

## Deployment
Use a Vercel preview for testing only after deployment settings are reviewed. Production remains on the approved production branch. Do not change production branch or domain settings without Palace authorization.
