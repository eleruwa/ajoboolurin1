# Eleruwa of Eruwaland — Premium Website Package

## Upload
Upload the entire contents of this folder to the root of the GitHub repository connected to your hosting provider.

The site is a static, responsive, multi-page package. It does not require Node.js or a server runtime.

## Pages
- `index.html` — Royal homepage
- `monarch.html` — Biography and royal profile
- `court.html` — Royal Court & Council
- `history.html` — History & Heritage
- `relics.html` — Relics & Antiquities
- `news.html` — News & Press
- `tourism.html` — Kingdom & Tourism
- `contact.html` — Audience, media and correspondence

The principal Eleruwa photographs are externally hosted photographs discovered on public news pages. Confirm permission/licensing before re-hosting or commercial reuse. Replace the URLs with Palace-owned originals as soon as the official media archive is available.
